- [ ] Replace all student/college/guide placeholders in the report.
- [ ] Install dependencies in a clean virtual environment.
- [ ] Run `pytest -q` and record the real result.
- [ ] Register a demo account and test login/logout.
- [ ] Prepare a text-based PDF and a DOCX test resume with fictional data.
- [ ] Test invalid file type and oversized file behavior.
- [ ] Demonstrate resume analysis, job matching, skill gaps, save job, and history.

## Suggested demo presentation (5–7 minutes)
1. Problem and objective (45 seconds).
2. Architecture and database (60 seconds).
3. Register/login and upload a resume (60 seconds).
4. Show detected skills and ranked roles (90 seconds).
5. Open a role and explain matched/missing skills (60 seconds).
6. Explain scoring formula and limitations (45 seconds).
7. Future scope and conclusion (30 seconds).
